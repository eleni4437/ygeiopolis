# Σύστημα Διαχείρισης Νοσοκομείου "Υγειόπολις" (Hospital Management System)

Το παρόν project αφορά τον σχεδιασμό και την υλοποίηση μιας Σχεσιακής Βάσης
Δεδομένων (RDBMS) για τη διαχείριση των λειτουργιών του νοσοκομείου "Υγειόπολης".
Το σύστημα καλύπτει τη διαχείριση προσωπικού, βαρδιών, ασθενών, νοσηλειών,
ιατρικών πράξεων και κοστολόγησης.

## Τεχνολογίες

- **RDBMS:** MariaDB (μέσω Docker)
- **Backend:** Python 3.x + Flask
- **Containerization:** Docker + Docker Compose
- **MySQL**: MySQL χρησιμοποιήθηκε για το στήσιμο, την φόρτωση και την διαχείρηση της βάσης δεδομένων καθώς και για το τρέξιμο των queries

## Εγκατάσταση και Εκτέλεση

### Προαπαιτούμενα

- Docker Desktop εγκατεστημένο και σε λειτουργία
- Python 3.x 

### Εκκίνηση με Docker (προτεινόμενο)

1. Κλωνοποίηση / αποσυμπίεση του project 'code'
2. Ενεργοποίηση του XAMPP
3. Τρέξιμο του path του folder 'code' και εκτέλεση των containers:
   ```bash
   docker-compose up --build
   ```
4. Η εφαρμογή είναι διαθέσιμη στο:
   ```
   http://127.0.0.1:5000
   ```
5. Η ΒΔ αρχικοποιείται αυτόματα με τα `install.sql` και `load.sql`

## Λειτουργία Βαρδιών & Μηχανισμοί Ελέγχου (Triggers)

Η διαχείριση των βαρδιών ελέγχεται από αυστηρά Triggers.
Για τη σωστή χρήση της βάσης από τους τελικούς χρήστες, ισχύουν οι εξής κανόνες:

1. **Σειρά Εισαγωγής Ιατρών:** Οι Ειδικευόμενοι ιατροί απαιτείται να έχουν
την επίβλεψη ανώτερου ιατρού. Συνεπώς, κατά την προσθήκη προσωπικού σε μια
βάρδια, ο χρήστης πρέπει **πάντα να προσθέτει πρώτα τους Διευθυντές/Επιμελητές**
και στη συνέχεια τους Ειδικευόμενους. Σε αντίθετη περίπτωση, το σύστημα δεν
θα επιτρέψει την καταχώρηση.

2. **Αντικατάσταση Υπαλλήλου (Rule of Substitution):** Αν επιθυμείτε να
αλλάξετε έναν υπάλληλο με κάποιον άλλον στην ίδια βάρδια, θα πρέπει **πρώτα
να αφαιρέσετε** τον υπάρχοντα υπάλληλο (`DELETE`) και **στη συνέχεια να εισάγετε**
τον νέο (`INSERT`). Με αυτόν τον τρόπο διασφαλίζεται ότι οι ελεγκτικοί μηχανισμοί
της βάσης θα τρέξουν σωστά και για τα δύο πρόσωπα ξεχωριστά, αξιολογώντας
σωστά τα όρια βαρδιών και αναπαύσεων.

3. **Κατάσταση Βάρδιας (Shift Status):** Επειδή μέσω των Triggers (που τρέχουν
ανά γραμμή) δεν είναι εφικτός ο έλεγχος των "λιγότερων απαιτούμενων υπαλλήλων"
τη στιγμή της δημιουργίας της βάρδιας, έχει προστεθεί στον πίνακα `shift_staff`
η στήλη `status`. Αυτή καθορίζει αν μια βάρδια πληροί όλες τις απαραίτητες
προϋποθέσεις για να θεωρηθεί έγκυρη, αφού ολοκληρωθεί η στελέχωσή της.

## Διαχείριση Προσωπικού

- **Διαθεσιμότητα (Staff Status):** Στον πίνακα `staff` έχει προστεθεί η στήλη
`status`, η οποία καθορίζει αν κάποιος υπάλληλος είναι διαθέσιμος ή παραβρίσκεται
ήδη σε κάποιο ενεργό πόστο (π.χ. χειρουργείο - `procedure`, ή στη διαλογή - `triage`).

- **Διευθυντές Τμημάτων (Dept Managers):** Έχει διασφαλιστεί ότι στις θέσεις
των διευθυντών τμημάτων τοποθετούνται αποκλειστικά ιατροί με τη βαθμίδα
"Διευθυντής", με απόλυτη αντιστοιχία ανάμεσα στην ιατρική ειδικότητα του
διευθυντή και το είδος του εκάστοτε τμήματος.

- **Ηλικιακό Όριο:** Για την απλοποίηση της υλοποίησης, θεωρήθηκε δεδομένο
κατά την εισαγωγή των δεδομένων ότι κάθε μέλος του προσωπικού είναι άνω των
25 ετών.

## Ασθενείς, Νοσηλείες & Κόστη

- **Κωδικοποίηση ΑΜΚΑ:** Τα πρώτα 6 ψηφία των ΑΜΚΑ (τόσο των ασθενών όσο και
του προσωπικού) ταυτίζονται απόλυτα με τις καταχωρημένες ημερομηνίες γέννησης,
διασφαλίζοντας τον ρεαλισμό των δεδομένων.

- **Διαχείριση Ανήλικων Ασθενών:** Στους ασθενείς πολύ μικρής ηλικίας, το
πεδίο εργασίας έχει οριστεί ως `ΑΝΕΡΓΟΣ`. Επιπλέον, τα στοιχεία επικοινωνίας
τους συνάδουν με τα στοιχεία του `emergency contact`, θεωρώντας πρακτικά ότι
είναι κάποιος κηδεμόνας που έδωσε τα δικά του στοιχεία.

- **Χωρητικότητα Κλινών:** Οι κλίνες με τύπο "πολύκλινο" μπορούν να φιλοξενήσουν
έως και τέσσερις (4) ασθενείς ταυτόχρονα.

- **Κωδικοί ΚΕΝ & Διπλοτυπίες:** Στη λίστα των ΚΕΝ παρατηρήθηκαν κάποιες
διπλοτυπίες στους επίσημους κωδικούς. Για την επίλυση του προβλήματος,
προστέθηκε έξτρα γράμμα **'Μ'** ή **'Χ'** ανάλογα με την περίπτωση
(π.χ. `Θ20Μ` και `Θ20ΜΜ`), ώστε να διασφαλιστεί η μοναδικότητα των εγγραφών.

- **Επιπλέον Χρέωση Νοσηλείας:** Η ημερήσια επιπλέον χρέωση για νοσηλείες
που υπερβαίνουν τον προβλεπόμενο χρόνο υπολογίζεται ως:
**βασικό κόστος ΚΕΝ ÷ μέσος χρόνος διαμονής** του συγκεκριμένου ΚΕΝ.
